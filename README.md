🎓  **<u>42 School</u>**

Projects developed throughout the 42 Common Core curriculum.

*Common Core*

- [Libft](https://github.com/jimmyIIx/libft) :  
 Custom C library developed from scratch, reimplementing several standard C functions.

- [ft_printf](https://github.com/jimmyIIx/ft_printf) :  
 Reimplementation of the standard printf function in C, using variadic functions.

- [get_next_line](https://github.com/jimmyIIx/get_next_line) :  
 Reads files line by line in C using file descriptors and static variables.

- [Push_swap](https://github.com/jimmyIIx/push_swap) :  
 Sorting algorithm developed in C using two stacks and a limited set of operations.

- [So Long](https://github.com/jimmyIIx/so_long) :  
 2D game developed in C using the MLX42 graphics library, recreating a Pac-Man-inspired level.

- [Philosophers](https://github.com/jimmyIIx/philosophers) :  
 Dining philosophers problem solved in C using threads and mutexes for synchronization.

- [Minishell](https://github.com/jimmyIIx/minishell) :  
 Lightweight UNIX shell developed in C with command parsing, pipes, redirections and environment variables.

- [Cub3D](https://github.com/jimmyIIx/cub3d) :  
 3D raycasting engine developed in C using MLX42, with textures and collision detection.

- [Pipex](https://github.com/jimmyIIx/pipex) :  
 Reimplementation of UNIX pipes, processes and redirections in C using system calls.

- [Webserv](https://github.com/jimmyIIx/webserv) :  
 HTTP server implemented in C++98, handling HTTP requests and multiple client connections using sockets.

- [CPP Modules](https://github.com/jimmyIIx/cpp-modules) :  
 C++ modules covering object-oriented programming, inheritance, polymorphism and templates.

- [Inception](https://github.com/jimmyIIx/inception) :  
 Docker-based infrastructure using Docker Compose, NGINX, WordPress and MariaDB.

- [Transcendence](https://github.com/jimmyIIx/transcendence) :  
 Full-stack virtual betting platform (42Bets) featuring virtual tokens, multilingual support and bet tracking.
