🎓 **<u>42 School</u>**

Projects developed throughout the 42 Common Core curriculum.

*Common Core*

- [Libft](https://github.com/jimmyIIx/libft) : Custom C library.
- [ft_printf](https://github.com/jimmyIIx/ft_printf) : Reimplementation of the standard printf function.
- [get_next_line](https://github.com/jimmyIIx/get_next_line) : Reads files line by line.
- [Push_swap](https://github.com/jimmyIIx/push_swap) : Sorting algorithm using two stacks and a limited set of operations.
- [So Long](https://github.com/jimmyIIx/so_long) : 2D game developed in C using MLX42.
- [Philosophers](https://github.com/jimmyIIx/philosophers) : Dining philosophers problem solved using threads and mutexes.
- [Minishell](https://github.com/jimmyIIx/minishell) : Lightweight UNIX shell with command parsing, pipes, redirections and environment variables.
- [Cub3D](https://github.com/jimmyIIx/cub3d) : 3D raycasting engine with textures and collision detection, built with MLX42.
- [Pipex](https://github.com/jimmyIIx/pipex) : Reimplementation of UNIX pipes, processes and redirections.
- [Webserv](https://github.com/jimmyIIx/webserv) : HTTP server implemented in C++, handling HTTP requests and multiple client connections.
- [CPP Modules](https://github.com/jimmyIIx/cpp-modules) : C++ modules covering object-oriented programming, inheritance and polymorphism.
- [Inception](https://github.com/jimmyIIx/inception) : Docker-based infrastructure with NGINX, WordPress and MariaDB.
- [Transcendence](https://github.com/jimmyIIx/transcendence) : Full-stack virtual betting platform (42Bets) featuring virtual tokens, multilingual support and bet tracking.
